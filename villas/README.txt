THE AURALIUS — THE VILLAS
=========================

A standalone, self-contained build of the The Villas page.

To view it
----------
Open index.html in any browser, or upload the whole folder
(index.html + assets/ + images/ + favicon.ico + og-image.png)
to any web host or static server. All paths are relative, so the
folder works from a domain root or from any sub-folder.

Contents
--------
index.html          the page
assets/             compiled CSS + JS
images/             photography used on the page (placeholders —
                    swap these files for the real villa photography,
                    keeping the same filenames)
favicon.ico         browser tab icon
og-image.png        social-share preview image
runable.js          unused legacy analytics file; the page does not load it

Note
----
The enquiry form has no backend in this static build — it opens the
visitor's mail client addressed to info@suryarealty.co.in. On the live
app version the submissions are stored in the database instead.
